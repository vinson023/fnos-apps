客户端怎么配

  1. 打开 RustDesk 客户端，进入 设置 → 网络。
  2. 勾选「启用 ID 服务器」，填入上面的 ID 服务器地址。
  3. 勾选「启用中继服务器」，填入上面的中继服务器地址。
  4. 把 Key 粘贴到「Key」输入框，保存后回到主界面。
  5. 主界面左下角显示「就绪」即代表已连上自建服务器。
